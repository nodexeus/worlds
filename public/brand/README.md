# Nodexeus identity assets

Official SVG sources from https://brand.nodexeus.com/ (retrieved 2026-10-05):

- `nodexeus-mark.svg`: `assets/logo/mark-amber-on-dark.svg`
- `nodexeus-mark-mono.svg`: `assets/logo/mark-mono.svg`
- `favicon.svg`: `assets/logo/favicon.svg`

Use the source glyph without tracing, recoloring, or distortion. These assets identify
Nodexeus; the repository's code license does not grant rights to the Nodexeus trademarks.

The desktop app's raster icons are generated from these SVGs by
`tools/build-desktop-icons.swift`. The app tile uses the official amber mark on brand ink;
macOS controls the monochrome menu-bar template's foreground color.
